## 1. はじめに

当社が運営する Stagecast (以下「本サービス」) は、利用者のプライバシーを尊重し、個人情報
保護法 (日本)・GDPR (欧州経済領域の利用者を対象とする場合)・その他関連法令を遵守して
個人情報を取り扱います。

## 2. 取得する情報の種類

### 2.1 利用者から直接取得する情報

| 種別                 | 内容                                                                | 取得タイミング |
| -------------------- | ------------------------------------------------------------------- | -------------- |
| 表示名               | 登壇者/モデレーターがステージ入室時に入力                           | 入室時         |
| 音声                 | マイクを ON にしたとき                                              | 配信中         |
| 映像                 | カメラを ON にしたとき                                              | 配信中         |
| 画面                 | 画面共有を ON にしたとき                                            | 配信中         |
| Email                | 管理者の Cognito アカウント作成時                                   | サインアップ時 |
| 登壇資料             | 翻訳の文脈と用語集に使う資料 (PDF / PPTX / Markdown / テキスト)     | アップロード時 |
| 申請者の氏名・連絡先 | イベント申請フォームに入力された氏名と連絡先 (メール / Slack ID 等) | 申請時         |

**イベント申請フォームは認証を要しません。** 申請者は本サービスのアカウントを持たない第三者で
ありうるため、氏名と連絡先の取扱いは 5 章の保管期間とあわせて確認してください。

### 2.2 自動的に取得する情報

| 種別             | 内容                                         | 取得目的                    |
| ---------------- | -------------------------------------------- | --------------------------- |
| 実行ログ         | 操作の種別・イベント ID・エラー内容          | 障害解析・セキュリティ監視  |
| ブラウザ保存領域 | テーマ、カレンダー表示、入出力デバイスの選択 | 画面設定の保持 (端末内のみ) |

本サービスは **IP アドレスや User-Agent を収集・保存していません** (API Gateway / CloudFront の
アクセスログを有効化していないため)。Cookie も使用していません。認証トークンは
ブラウザの `sessionStorage`、画面設定は `localStorage` に保持され、いずれも**利用者の端末内に留まります**。

## 3. 利用目的

取得した情報は、以下の目的で利用します:

1. ライブ配信の WebRTC 経由での中継 (LiveKit Server / Egress 経由)
2. 字幕の自動生成
   - **音声が送られるのは Amazon Transcribe のみ**です (ストリーミング音声認識)
   - Amazon Translate と Amazon Bedrock に送られるのは、**認識結果のテキストと登壇資料の本文**です (音声そのものは送られません)
3. 録画ファイルの S3 保存と管理者へのダウンロード提供
4. YouTube Live への RTMP 送出 (映像・音声・字幕)
5. 障害解析・セキュリティ監視 (CloudWatch Logs)
6. 利用統計の集計 (個人を特定しない形)

## 4. 第三者提供

以下の場合を除き、利用者の同意なく個人情報を第三者に提供しません:

| 提供先                    | 提供する情報                                     | 目的                                             |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------ |
| Amazon Web Services, Inc. | 音声、映像、表示名、字幕テキスト、登壇資料の本文 | サービスインフラ提供 (本サービスは AWS 上で稼働) |
| Google LLC (YouTube)      | 映像、音声、字幕                                 | YouTube Live 配信                                |
| 法令に基づく開示請求者    | 必要最小限                                       | 法令遵守                                         |

AWS および YouTube のプライバシーポリシーは、各社の公開規定をご参照ください。

### 4.1 外国にある第三者への提供 (越境移転)

本サービスの主要なインフラは**東京リージョン (ap-northeast-1)** で稼働しますが、
**一部の処理は米国リージョンで行われます**。

| 処理                                  | リージョン                | 送られる情報                 |
| ------------------------------------- | ------------------------- | ---------------------------- |
| Amazon Bedrock による翻訳・用語集生成 | **米国 (us-east-1 ほか)** | 字幕テキスト、登壇資料の本文 |

Bedrock はクロスリージョン推論プロファイル (`us.` で始まるモデル ID) を使用しており、
**米国内の複数リージョンで処理されうる**点にご留意ください。

> **運用者向け**: 個人情報保護法の外国にある第三者への提供、および GDPR 第 5 章
> (第三国移転) の要件を満たすため、提供先の国名・同意取得の方法・移転の根拠を
> 弁護士と確認してください。字幕エンジンに `transcribe` のみを使う運用にすれば、
> Bedrock への送信自体を無くせます (ADR 0017)。

## 5. データの保管期間

> ⚠️ **公開前に必ず確認すること。** 以下は 2026-09-17 時点の**実装の実態**であり、
> 保管期間を定めていない項目があります。実態と違う期間を書いた規約は、無いより危険です。
> 「要決定」の行は、運用者が期間を決めて**実装側にも反映**してから公開してください。

| 種別                        | 保管期間 (実装の実態)                                                       | 保管場所         |
| --------------------------- | --------------------------------------------------------------------------- | ---------------- |
| 録画ファイル                | **無期限** (30 日で低頻度アクセス、90 日で Glacier に移行するのみ) ← 要決定 | Amazon S3        |
| 字幕ファイル (SRT/VTT)      | **無期限** (期限のルール無し) ← 要決定                                      | Amazon S3        |
| 登壇資料 (翻訳参考資料)     | **イベント終了時に自動削除**                                                | Amazon S3        |
| 翻訳用語集                  | **イベント終了時に自動削除**                                                | Amazon Translate |
| イベント申請 (氏名・連絡先) | **無期限** (期限のルール無し) ← 要決定                                      | Amazon DynamoDB  |
| 実行ログ                    | メディア層 1 週間 / 調整ループ 1 ヶ月 / その他は**無期限** ← 要決定         | CloudWatch Logs  |
| 管理者アカウント            | 退会まで                                                                    | Amazon Cognito   |

### 5.1 削除の実効性について

- S3 のオブジェクトを削除すると、**旧バージョンは 7 日後に完全に削除**されます
  (バケットはバージョニング有効なため、削除直後は旧バージョンが残ります)。
  誤削除から復旧できる猶予であり、7 日を過ぎると復元できません。
- DynamoDB は **Point-in-Time Recovery が有効**で、データを削除しても
  **35 日間はバックアップから復元可能**です。完全な消去を求められた場合は、
  この点を踏まえた対応が必要です。
- **Glacier に移行した録画 (90 日経過後) は、そのままではダウンロードできません。**
  復元処理が未実装のため、長期保管した録画を提供する運用にする場合は実装が必要です。

## 6. 利用者の権利 (個人情報保護法 / GDPR)

利用者は、自身の個人情報について以下の権利を持ちます:

- アクセス権 (どんな情報が保管されているか開示請求)
- 訂正・削除請求権
- 利用停止請求権
- データポータビリティ (GDPR 該当者のみ)

権利行使は、お問い合わせ先にご連絡ください。原則 30 日以内に対応します。

> **運用者向け**: 削除請求に応じる際は 5.1 の制約に注意してください。S3 の旧バージョンは
> 削除から 7 日、DynamoDB は Point-in-Time Recovery により 35 日、それぞれ復元可能な状態が
> 残ります。「直ちに完全消去」を約束するとこの実装では守れません。

## 7. Cookie とブラウザの保存領域

**本サービスは Cookie を使用していません。** 第三者トラッキング (広告等) も使用しません。

利用者の端末内には、以下がブラウザの保存領域に置かれます。いずれも**サーバーには送られません**。

| 保存先           | 内容                                         | 目的               |
| ---------------- | -------------------------------------------- | ------------------ |
| `sessionStorage` | Cognito の ID トークン (管理コンソール)      | ログイン状態の維持 |
| `localStorage`   | テーマ、カレンダー表示、入出力デバイスの選択 | 画面設定の保持     |

招待トークンは URL に含まれ、**ブラウザの保存領域には保存されません** (画面を閉じると消えます)。

## 8. セキュリティ

当社は以下のセキュリティ対策を講じています:

- 通信の暗号化 (HTTPS / WSS / TLS)
- AWS Secrets Manager による機密情報の管理
- IAM 最小権限の原則
- CloudFront による DDoS 緩和
- AWS Cognito による多要素認証 (オプション)

## 9. 子どもの個人情報

本サービスは原則として 16 歳未満の利用を想定していません。16 歳未満の利用者が本サービスを
利用する場合は、保護者の同意が必要です。

## 10. プライバシーポリシーの変更

当社は、本ポリシーを予告なく変更することがあります。重要な変更がある場合は、本サービス上で
通知します。
