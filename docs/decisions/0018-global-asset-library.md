# ADR 0018: 配信素材をイベント非依存のグローバルライブラリで管理する

- **ステータス**: 採用
- **日付**: 2026-09-07
- **関連**: DESIGN.md F-10 / 8 章, ADR 0014

## コンテキスト

DESIGN.md F-10 と 8 章は「イベントごとに素材を準備・登録する」とし、S3 キーも `assets/{eventId}/` で
イベントに紐付けていた。実運用では同じロゴ・背景・テロップ素材を複数イベントで使い回すことが多く、
イベントごとに再アップロードする手間と重複ストレージが発生していた。

## 決定

- 素材メタデータ (`AssetMetadata`) は `eventId` を持たず、タグと説明で分類するグローバルライブラリにする。
- S3 キーは `assets/library/<assetId>-<filename>` に統一する。
- admin-web に `/library` 画面を置き、stage-web の演出プリセット (ADR 0014 の画面責務) は
  ライブラリの `assetKey` を参照する。
- イベント削除時の S3 クリーンアップ対象から `assets/` を外す (録画・字幕のみ削除)。

## 影響・トレードオフ

| 項目                 | 変更前                       | 変更後                                       |
| -------------------- | ---------------------------- | -------------------------------------------- |
| 素材の再利用         | イベントごとに再アップロード | 1 回登録して複数イベントで参照               |
| イベント削除時の掃除 | `assets/{eventId}/` を削除   | 素材は残る (`DELETE /assets/:id` で個別削除) |
| 権限                 | Cognito 管理者のみ           | 一覧/取得は招待トークン (moderator) でも可   |

- 旧形式 `assets/{eventId}/` に残っている既存オブジェクトは自動移行しない (手動削除)。
- stage-web からの取得 URL 発行はライブラリ登録済みキーに限定する (任意キーの presign を禁止)。
